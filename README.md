## Field kits

Go-to-market systems you can run: five kits, one made-up company, and a measured result in every README.

**Start at [`field-kit`](https://github.com/meinsta/field-kit).** It explains the path, runs all five
kits with one script, and holds the code they share. Each kit matches a system on [meina.me](https://meina.me).

| # | Kit | What it does |
|---|---|---|
| 1 | [`grounding-layer`](https://github.com/meinsta/grounding-layer) | A scheduled refresh that keeps product and field sources current in Qdrant, ending in a recall gate. |
| 2 | [`org-knowledge-mcp`](https://github.com/meinsta/org-knowledge-mcp) | An MCP server that answers from your own sources and checks that every claim is cited. |
| 3 | [`field-systems`](https://github.com/meinsta/field-systems) | Field cards built from those sources, with a weekly check that proposes a fix when a source changes. |
| 4 | [`field-guides`](https://github.com/meinsta/field-guides) | Deal-backed guide outlines that keep what ships today apart from what is still open, with expert review. |
| 5 | [`page-engine`](https://github.com/meinsta/page-engine) | Product pages and paid landings where every detail is a docs sentence and authored words are judged in code. |
